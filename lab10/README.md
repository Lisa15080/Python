Выводы:
Потоки в Python не дают ускорения из-за GIL 
Процессы в Python ускоряют вычисления (до 3.5× при 8 ядрах)
Cython (однопоточный) в 14× быстрее 
Cython + потоки почти не ускоряются по сравнению с обычным Cython
Cython + процессы медленнее однопоточного Cython, так как накладные расходы на запуск процессов перевешивают выгоду
При использовании nogil в Cython время уменьшается почти пропорционально числу потоков

Вопросы:
1. Нужны ли примитивы синхронизации?
Нет, так как каждый поток и процесс работает на своем подынтервале. 
Общих изменяемых данных и конкуренции нет, результаты суммируются в конце.
2. Что с GIL в Python 3.14? Нужно ли отпускать GIL?
Python 3.14 созхраняет GIL. Чтобы добиться параллелизма в потоках, GIL нужно
отпускать с помощью Cython
